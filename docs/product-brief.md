# Product Brief — 친구용 베팅 게임 사이트

- 작성일: 2026-09-30
- 사용자: 친구 최대 10명 (비공개, 초대제)
- 배포: 웹 (모바일 브라우저 우선)

## 목표
짧고 강한 도파민 루프를 가진 인스턴트 게임 + 친구끼리 거는 예측 베팅을 **가상 포인트**로 즐긴다.

## 범위
| 영역 | 항목 |
|---|---|
| 인스턴트 게임 | Dice, Limbo, Wheel, Plinko |
| 멀티스텝 게임 | Mines, Chicken Road, HiLo |
| 실시간 멀티 | Crash (전원이 같은 라운드) |
| 소셜 베팅 | 친구 예측 베팅 (패리뮤추얼, 방장 확정) |
| 공통 | 로그인, 포인트 지갑, 실시간 피드, 랭킹, 출석/미션, 칭호/뱃지, 연출(카운트업·효과음) |

## 제약
- 가상 포인트만. 현금 충전·환전·포인트 거래 기능 없음 (형법 246·247조 회피).
- 결과는 서버가 결정 (클라이언트 조작 불가), provably fair 검증 가능.
- 가입 10,000P, 파산 시 일일 구제금.

## 성공 기준
- 10명이 동시에 Crash 한 라운드에 참여하고 캐시아웃 결과가 모두에게 1초 내 보인다.
- 어떤 게임이든 동시 요청으로 잔액이 음수가 되거나 이중 지급되지 않는다.
- 모든 판의 결과를 seed 공개 후 사용자가 재계산할 수 있다.
