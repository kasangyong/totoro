# 규칙: 섯다 · 7포커 · 홀덤 · 블랙잭 (멀티 방 게임)

- 작성일: 2026-09-30 (rev.2 — 평가 1차 "보통" 반영)
- 범위: 섯다(2장·3장)·포커(7포커·홀덤)·블랙잭. 고스톱은 보류.
- 기준: 국내에서 가장 많이 하는 방식(한게임·피망 기준). 출처에 없는 세부는 **[우리 규칙]** 으로 표시.
- 공통 전제: 가상 포인트만, 결과는 서버가 정함, 판마다 검증 정보 공개 (설계는 별도 문서).

## 공통 베팅 (한국식 팟 베팅)

### 용어
- **H** = 이번 라운드에서 한 사람이 낸 최고 금액 (라운드 시작 시 0).
- **내 기여** = 이번 라운드에 내가 낸 금액. **콜 금액** = H − 내 기여.
- **팟** = 이번 판에 쌓인 전체 금액 (앤티 포함).
- **보스(선)** = 이번 라운드에 먼저 액션하는 사람. 차례는 좌석 번호 오름차순(시계 방향), 다이한 사람은 건너뜀.

### 액션
| 액션 | 가능 조건 | 결과 (내 이번 라운드 기여를 얼마로 만드나) |
|---|---|---|
| 체크 | H = 0 | 0 그대로 |
| 삥 | H = 0 **이고 보스만** | 기본금 |
| 콜 | H > 0 | H |
| 따당 | H > 0 | **2H** (앞 사람이 건 금액의 2배, 한게임 정의) |
| 쿼터 | 항상 | H로 맞춘 뒤 그 시점 팟 × 1/4 추가 |
| 하프 | 항상 | H로 맞춘 뒤 그 시점 팟 × 1/2 추가 |
| 다이 | 항상 | 포기. 이미 낸 돈은 팟에 남음 |

- 따당·쿼터·하프 = **레이즈**. **[우리 규칙]** **한 라운드에 한 사람당 레이즈 최대 2회** (확정). 다 쓴 사람은 콜·다이(·H=0이면 체크)만. 따당·쿼터·하프 모두 유지.
- **[우리 규칙]** 체크는 보스뿐 아니라 H=0인 동안 누구나 가능. **전원 체크하면 라운드 종료.**
- **[우리 규칙]** 지정된 보스가 이미 다이·올인이면, 그 라운드에 처음 액션하는 사람(좌석 순)이 보스 역할(삥 권한)을 넘겨받음.
- **[우리 규칙]** 나 말고 액션할 수 있는 사람이 없으면(나머지 전원 다이·올인) 레이즈 불가 — 콜·체크·다이만.
- **[우리 규칙]** 쿼터·하프 레이즈 폭은 최소 1포인트 (팟이 아주 작아 내림하면 0이 되는 경우).
- 라운드 종료: (a) 남은 전원이 이번 라운드에 한 번 이상 액션했고 각자 기여 = H 또는 올인 (전원 체크 포함), (b) 1명만 남음 → 그 사람이 팟 전부.
- **[우리 규칙]** 따당·쿼터·하프·콜 금액이 보유 포인트보다 크면 **올인으로 제한**.
- 판 시작 시 전원 **기본금(앤티)** 을 팟에 냄. 기본금 = 삥 금액 = 방 설정값.
- **[우리 규칙]** 턴 타이머 20초. 초과 시 H=0이면 체크, 아니면 다이. 연결 끊김도 동일.
- 금액은 정수 포인트, 소수점 이하 내림.

### 올인 · 사이드팟
- 보유 포인트로 콜 금액을 못 채우면 **올인**(전부 걸기). 올인한 사람은 이후 액션 없이 끝까지 감.
- 정산: 기여액 기준으로 메인팟·사이드팟을 나누고, 각 팟은 **그 팟에 자격 있는 사람 중** 최고패가 가져감.
- **[우리 규칙]** 방 입장·착석 최소 보유 = 기본금 × 10. 판이 끝났을 때 스택이 기본금보다 적으면 **자동으로 일어서며 남은 스택 반환** (관전은 가능, 구제금 받고 다시 착석 가능).

## 섯다 (2장 섯다)

"기본적으로 2장 섯다가 표준"이라 2장 섯다를 기본으로 채택. 3장 섯다는 방 만들기에서 방식으로 고른다 (아래 "3장 섯다", 2026-10-02 추가).

### 패
- 화투 20장: 1~10월 각 2장 (월마다 특수패 1장 + 일반패 1장).
- 규칙에 쓰이는 특수패: **광** 1·3·8월, **열끗** 4·7·9월.

### 진행
1. 인원 2~6명. 전원 기본금.
2. **1장씩 받음 → 1차 베팅** (보스부터).
3. **1장 더 받음 → 2차 베팅**.
4. 남은 사람끼리 패 공개 → 아래 판정 알고리즘.
- 보스 = 직전 판 승자, 첫 판은 방장. 두 라운드 모두 같은 보스. **[우리 규칙]** (1차에서 보스가 다이·올인했으면 2차는 공통 베팅의 보스 인계 규칙을 따름)

### 족보 (높은 순)
| 순위 | 족보 | 조합 |
|---|---|---|
| 1 | 삼팔광땡 | 3광 + 8광 (무적) |
| 2 | 일팔광땡 · 일삼광땡 (동급) | 1광 + 8광 / 1광 + 3광 |
| 3 | 땡 | 같은 월 2장. 장땡(10) > 9땡 > … > 1땡(삥땡) |
| 4 | 알리 | 1 + 2 |
| 5 | 독사 | 1 + 4 |
| 6 | 구삥 | 1 + 9 |
| 7 | 장삥 | 1 + 10 |
| 8 | 장사 | 4 + 10 |
| 9 | 세륙 | 4 + 6 |
| 10 | 끗 | 두 월 합의 일의 자리. 갑오(9끗) > 8끗 > … > 1끗 |
| 11 | 망통 | 0끗 |

### 특수패
| 패 | 조합 | 잡는 것 | 평소 값 |
|---|---|---|---|
| 암행어사 | 4열끗 + 7열끗 | 일삼·일팔광땡 (삼팔광땡 못 잡음) | 1끗 |
| 땡잡이 | 3광 + 7열끗 | 1땡~9땡 (장땡·광땡 못 잡음) | 망통 |
| 구사 | 4 + 9 (멍텅구리 아닌 것) | — (재경기 유발: 상대 최고패 ≤ 알리) | 3끗 |
| 멍텅구리 구사 | 4열끗 + 9열끗 | — (재경기 유발: 상대 최고패 ≤ 9땡) | 3끗 |

### 판정 알고리즘 (3명 이상 포함) **[우리 규칙]**
각 팟마다, 그 팟 자격자 중 다이 안 한 사람으로:
1. 모든 패를 **평소 값**으로 순위 매김.
2. **잡기**: 현재 1위가 일삼·일팔광땡이고 암행어사 보유자가 있으면, 또는 1위가 1~9땡이고 땡잡이 보유자가 있으면 → **잡은 사람이 그대로 이김** (확정). 1위가 38광땡·장땡이면 잡기 없음.
3. **구사 재경기**: 남은 후보에 구사(멍텅구리) 보유자가 있고, 구사 보유자를 뺀 최고패가 알리 이하(멍텅구리는 9땡 이하)면 → 재경기.
4. 1위가 여러 명(같은 족보·같은 끗)이면 → 그 사람들끼리 재경기.
5. 아니면 1위가 팟을 가져감.

예시: [일팔광땡, 9땡, 암행어사] → 암행어사 승. [9땡, 알리, 땡잡이] → 땡잡이 승. [장땡, 5땡, 땡잡이] → 장땡 못 잡음 → 장땡 승. [38광땡, 18광땡, 암행어사] → 38광땡 승.

### 재경기 **[우리 규칙]**
- 팟이 여러 개면 **재경기가 필요 없는 팟을 먼저 정산**하고, 재경기는 재경기가 걸린 팟(들)의 참가자끼리만.
- 참가: 재경기 사유가 된 사람만 (3번은 그 팟에서 다이 안 한 전원, 4번은 동점자). 올인한 사람도 참가하되 추가 베팅 없음.
- **구사 재경기 재참여 (확정)**: 이번 경기에서 다이한 사람도 **판돈의 절반**을 내면 참여 가능. 동점 재경기에는 없음. 참여 여부는 전원 동시에 정하고(누가 참여했는지는 전원이 정한 뒤 공개), 기한 안에 안 정하면 불참. 스택이 참여금보다 적으면 참여 불가. **[우리 규칙]** 구사와 동점 재경기가 한 판에 같이 나면 판돈·참여금·자격은 **구사 팟에만** 적용 (참여금은 첫 구사 팟에 더함).
- 보스는 직전 판 보스 유지.
- 재경기에서 이월된 팟의 자격자가 모두 다이하면 그 팟은 원래 자격자끼리 균등 분배 (나머지는 좌석 번호가 가장 낮은 사람). 자격자가 1명만 남으면 그 사람이 가져감.
- 혼자 남아 이기면(나머지 전원 다이) 패를 공개하지 않음. 판 종료 후 검증 공개는 별도.
- 팟은 그대로 이월, 기본금 추가 없음, 새로 섞은 패로 1차 베팅부터 다시.
- 연속 3회 재경기 후에도 결론이 안 나면 해당 팟을 참가자에게 균등 분배 (내림, 나머지는 좌석 번호가 가장 낮은 참가자에게).

### 공개 범위
- 판이 끝나면 검증을 위해 덱 전체가 공개되므로 **다이한 사람의 패도 공개됨** (포커도 동일).

### 3장 섯다 (방식 선택) — 설계: [sutda3-arch.md](sutda3-arch.md)
족보·판정·재경기·재참여는 2장 섯다와 같고, 진행만 다르다 ([나무위키 섯다](https://namu.moe/w/%EC%84%AF%EB%8B%A4)).
1. 보스부터 한 장씩 **두 바퀴** (2장, 숨김).
2. **공개 선택**: 2장 중 1장을 고름 (전원 동시, 정할 때까지 무엇을 골랐는지 비공개) → 전원이 정하면 동시에 공개. **[우리 규칙]** 15초 안에 안 고르면 월이 낮은 카드 (같은 월이면 일반패).
3. **1차 베팅**.
4. 살아 있는 사람에게 보스부터 1장 더 (숨김).
5. **조합 선택**: 3장 중 쓸 2장 (전원 동시, 쇼다운 전까지 본인만 앎). 공개한 카드를 버려도 된다. **[우리 규칙]** 15초 안에 안 고르면 평소 값이 가장 높은 조합 (땡잡이·암행어사·구사는 평소 값이 낮아 자동으로는 안 고름).
6. **2차 베팅** → 쇼다운: 고른 2장만 공개해 판정. 숨긴 채 버린 카드는 판이 끝난 뒤 검증 공개 때만 드러남.
- 재경기도 1번부터 3장 흐름 그대로. 6명 × 3장 = 18장 ≤ 20장.

## 포커 (7포커 · 초이스 룰)

국내에서 "포커"라고 하면 보통 세븐포커. 친구가 말한 "처음에 4장 받고 1장 버리는 것"이 **초이스 룰**이라 채택. 텍사스 홀덤은 아래 "텍사스 홀덤" 절에 있다.

### 패
- 조커 없는 52장 1덱. **인원 2~6명** (한 명이 8장을 받고 1장 버림 → 8 × 6 = 48장).

### 진행
1. 전원 기본금.
2. **4장 받음 → 1장 버리고, 남은 3장 중 1장을 오픈** (전원 동시 선택, 전원이 고를 때까지 **무엇을** 골랐는지는 비공개 (누가 이미 골랐는지는 표시). 기한은 한 번 정해지면 누가 골라도 늘어나지 않음. **[우리 규칙]** 타이머 초과 시 가장 약한 카드를 버리고 남은 카드 중 가장 약한 카드를 공개 — 검증 재생이 가능하도록 무작위 대신 정해진 규칙).
3. **4구**(오픈) → 베팅.
4. **5구**(오픈) → 베팅.
5. **6구**(오픈) → 베팅.
6. **7구 = 히든**(본인만 봄) → 마지막 베팅.
7. 남은 사람끼리 7장 중 최고 5장으로 비교.
- 베팅은 **4구부터** (4구룰), 라운드 4번.
- 매 라운드 **보스 = 오픈 카드가 가장 높은 사람**. 오픈 카드(2~4장)만으로 포카드 > 트리플 > 투페어 > 원페어 > 탑 순 평가 (5장 족보는 오픈 카드로 못 만듦). 같으면 아래 동점 판정과 같은 방식.

### 족보 (높은 순, 국내 기준)
| 순위 | 족보 |
|---|---|
| 1 | 로열 스트레이트 플러시 (A-K-Q-J-10 같은 무늬) |
| 2 | 백 스트레이트 플러시 (A-2-3-4-5 같은 무늬) |
| 3 | 스트레이트 플러시 |
| 4 | 포카드 |
| 5 | 풀하우스 |
| 6 | 플러시 |
| 7 | 마운틴 (A-K-Q-J-10) |
| 8 | 백 스트레이트 (A-2-3-4-5) |
| 9 | 스트레이트 |
| 10 | 트리플 |
| 11 | 투페어 |
| 12 | 원페어 |
| 13 | 탑 (하이카드) |

### 동점 판정 (족보 → 숫자 → 무늬)
- 무늬 순서: **스페이드 > 다이아 > 하트 > 클로버**. 숫자: A > K > … > 2.
- 족보가 같을 때 **족보를 이루는 카드만** 비교, 키커는 보지 않음 **[한게임식 해석, 우리 규칙]**:

| 족보 | 숫자 비교 | 그래도 같으면 무늬 비교 대상 |
|---|---|---|
| 스트레이트·스티플·플러시·탑 | 가장 높은 카드부터 차례로 | 가장 높은 카드의 무늬 |
| 마운틴·로티플 | (같음) | A의 무늬 |
| 백스트레이트·백스티플 | (같음) | **A의 무늬** (한게임 명시) |
| 포카드 | 포카드 숫자 | (숫자가 같을 수 없음) |
| 풀하우스 | 트리플 숫자 | (같을 수 없음) |
| 트리플 | 트리플 숫자 | (같을 수 없음) |
| 투페어 | 높은 페어 → 낮은 페어 | 높은 페어 중 높은 무늬 |
| 원페어 | 페어 숫자 | 페어 중 높은 무늬 |

- 무늬까지 보면 두 패가 완전히 같을 수 없으므로 팟을 나누는 경우는 없음 (사이드팟 자격 차이 제외).

| 블라인드 | BB = 기본금, SB = 기본금 절반(내림). 앤티 없음. 기본금 2P 이상 |
| 버튼 | 판마다 좌석 순서로 다음 참가자. 첫 판은 방장. **[우리 규칙]** 데드 버튼 없음 |
| 카드 | 버튼 왼쪽부터 개인 카드 2장씩. 공용 카드는 번 1장 후 플랍 3장, 번 1장 후 턴, 번 1장 후 리버 |
| 순서 | 프리플랍은 BB 왼쪽부터, 플랍부터는 버튼 왼쪽부터. 헤즈업은 버튼(SB)이 프리플랍 먼저, 이후는 BB 먼저 |
| 액션 | 폴드 · 체크 · 콜 · 레이즈(총액) · 올인. 최소 벳 = BB, 최소 레이즈 = 직전 레이즈 크기만큼 더. 최대 = 가진 것 전부 |
| 짧은 올인 | 최소 레이즈보다 적게 올린 올인은 이미 행동한 사람에게 레이즈를 다시 열지 않음. **[우리 규칙]** 여러 번 겹쳐도 합산하지 않음. BB보다 적은 첫 올인 뒤 최소 레이즈는 그 금액 + BB |
| 시간 초과 | 체크할 수 있으면 체크, 아니면 폴드 (20초) |
| 쇼다운 | 7장 중 가장 좋은 5장. 키커로 가리고 무늬는 안 봄, 같으면 나눔. 사이드팟 지원. **[우리 규칙]** 나누고 남는 칩은 좌석 번호가 가장 낮은 수령자 |
| 족보 | 하이카드 < 원페어 < 투페어 < 트리플 < 스트레이트(A-2-3-4-5가 가장 낮음) < 플러시 < 풀하우스 < 포카드 < 스트레이트 플러시(로열 플러시) |
| 공개 | 혼자 남아 이기면 패를 보여 주지 않음. 판이 끝나면 검증을 위해 덱 전체가 공개되므로 폴드한 사람의 카드도 그때 드러남 |
| 바이인 | 최소 BB × 10 (**[우리 규칙]**, 다른 방과 같음) |

## 블랙잭 (서버 딜러)
설계와 근거: [blackjack-arch.md](blackjack-arch.md). 사람끼리가 아니라 **각자 딜러와** 대결하고, 포인트는 하우스와 정산한다.

| 항목 | 규칙 |
|---|---|
| 덱 | 6덱(312장), 판마다 새로 섞음 (RNG v1, 초기 순서는 포커 순서 × 6) |
| 인원 | 1~6명 (혼자서도 시작) |
| 베팅 | 동시에 15초. 기본금 이상, 가져온 포인트까지(최대 1,000,000P), **짝수만**. "이번 판 쉬기" 가능. 안 정하면 불참 |
| 딜 | 좌석 순 1장 → 딜러 오픈 → 좌석 순 1장 → 딜러 히든 |
| 딜러 확인(peek) | 딜러 오픈이 A·10점이면 히든 확인 → 딜러 블랙잭이면 바로 정산 (참가자 블랙잭은 무승부, 나머지는 처음 건 돈만 잃음) |
| 참가자 블랙잭 | 처음 2장이 A + 10점 → 턴 없이 **3:2** |
| 턴 | 좌석 순, 20초. 히트·스탠드·더블·스플릿. 시간 초과 = 스탠드 |
| 더블 | 손의 처음 2장일 때(스플릿 뒤 손 포함), 같은 금액 더 걸고 1장만 |
| 스플릿 | 처음 2장 점수가 같으면(10·J·Q·K끼리 포함) 1번. 둘째 손은 차례가 오면 카드를 받음. A는 한 장씩만 받고 끝. 스플릿 뒤 A+10은 21(1:1) |
| 딜러 | 버스트도 블랙잭도 아닌 손이 있으면 17 이상까지 받고, **소프트 17에서도 멈춤** |
| 지급 | 블랙잭 3:2, 승 1:1, 무승부 돌려받음, 버스트·패 잃음 |
| 방치 | 판 도중 10분 넘게 아무도 없어 방이 청소되면 **건 돈은 잃음** (판을 무르는 악용 방지) |
| RTP | 기본 전략 기준 약 99.5% (1,000만 판 시뮬레이션). 실력이 들어가는 게임 |
